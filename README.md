# Questions & Truth – Online-PC-Version

## Lokal starten
1. Node.js installieren: https://nodejs.org/
2. Terminal in diesem Ordner öffnen
3. `npm install`
4. `npm start`
5. Auf dem PC `http://localhost:3000` öffnen

## Mit Freunden über unterschiedliche Geräte
Für einen schnellen Test im gleichen WLAN: Host-PC-IP statt localhost verwenden, z.B. `http://192.168.x.x:3000`.

Für Spielen über das Internet muss die App auf einem Hosting-Dienst (z.B. Render/Railway/VPS) bereitgestellt werden. Dann bekommt ihr einen Link, über den beide beitreten können.

Hinweis: Dies ist eine Fan-Nachbildung der im Chat beschriebenen Spielmechanik und kein offizielles Netflix-Spiel.
